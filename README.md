# ShopEase E-Commerce Sales Analytics

## Project Overview
An E-Commerce Sales Analytics project developed using SQL, Python, and Power BI to analyze sales performance, customer behavior, products, orders, and marketing campaigns.

## Tools & Technologies
- MySQL
- Python
- Pandas
- Power BI
- Power Query
- DAX
- Excel / CSV

## Project Workflow
1. Raw CSV data collection
2. Data cleaning and transformation using SQL
3. Data cleaning and analysis using Python
4. Cleaned data loaded into Power BI
5. Data modeling and DAX calculations
6. Interactive Power BI dashboard development
7. Business insights and recommendations

## Dataset
The project contains the following datasets:
- Customers
- Marketing Campaigns
- Orders
- Order Items
- Products
- Orders Cleaned

## Dashboard
The Power BI dashboard provides insights into:
- Sales Performance
- Order Analysis
- Customer Analysis
- Product Performance
- Marketing Campaign Analysis
- Payment Methods
- Order Status
- Discounts and Returns
